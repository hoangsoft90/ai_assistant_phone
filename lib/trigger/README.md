# `lib/trigger/` — trigger abstraction

Chưa có file Dart nào. Được điền ở **P3**.

Dự kiến: tách "cái gì kích hoạt gợi ý" (mục 4.6) khỏi "gợi ý nội dung gì", để sau này thêm
trigger mới (nút bấm thủ công → semi-auto mode P6) mà không phải sửa Suggestion Engine.

Trạng thái hiện tại: chỉ có **1 trigger** là Push thủ công của người dùng.
